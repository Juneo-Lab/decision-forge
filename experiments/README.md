# Experiment archive

Every model-backed experiment lives here as raw artifacts, not as a summary: prompts are excluded,
but the recorded responses, failures, usage journals, quarantine decisions, and cost ledgers are kept.
Nothing in this directory is regenerated by CI, so the files are the primary evidence.

## Reading the archive

- **Naming.** Directory names are `YYYY-MM-<milestone>/<model>-<effort>/`.
- **Failures are kept.** A run that failed validation or produced a rejected review item stays in the
  archive with its usage entry. Where a provider returned no cost, the entry records the cost as
  unknown rather than zero, so totals are lower bounds.
- **No labels were repaired.** Rejected items are preserved as rejected; scores are not adjusted after
  the fact.
- **References are author-written.** The evaluation fixtures were written by the maintainers before
  inspecting model output. They are not an external benchmark and not independent expert annotation.
- **Determinism boundary.** Model generation is stochastic; replaying the saved specifications against
  the policy engine is deterministic.

## Reproducing

Each directory's `README.md` lists the exact command, endpoint, model identifier, reasoning effort,
and token limits. Reproducing a run requires an API key and produces new costs; replaying the archived
artifacts does not.

## What these runs do not establish

They establish compatibility, failure behaviour, and cost on small fictional inputs. They do not
establish performance on real organizational documents, and no downstream fine-tuning experiment has
been run, so no claim is made that this data improves a model's decisions.
